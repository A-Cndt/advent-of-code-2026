# Changelog

All notable changes to this project will be documented in this file.

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-17

### Added
- Initial stable release of Advent of Code 2026.
- Modern desktop graphical interface built with PySide6.
- Dark theme and user-friendly interface.
- Tab-based navigation and day selection.
- Direct access to Advent of Code puzzle statements.
- Puzzle input and example management.
- Advent of Code session token management.
- Independent execution of Part 1 and Part 2.
- Sequential execution of both puzzle parts.
- Execution time measurement.
- Standard output capture and display.
- Expected result validation for puzzle examples.
- Error handling and execution feedback.
- Keyboard shortcuts for common actions.
- Local persistence of application data and settings.
- Modular architecture separating GUI and business logic.

### Quality & Security
- Automated unit testing with Pytest.
- Code coverage reporting with pytest-cov.
- Static type checking with Mypy.
- Code linting and quality checks with Ruff.
- Security vulnerability scanning with Bandit.
- Continuous Integration pipeline for automated validation.

### Technical
- Python 3.13+ support.
- PySide6 graphical framework.
- Modular source code organization.
- Day-based solution directory structure.
